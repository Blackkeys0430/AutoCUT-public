## 这次统一解决什么

现有资料过去分散在教程、拉片、模板工程和单条分析中。它们分别回答了“有什么效果”“别人怎么做”“素材放在哪里”，但没有统一回答最关键的问题：**当前这句口播为什么需要这个画面变化**。

以下因果链用于理解教程和选择表现，不是每个节点另填一套表或重跑一轮规划；当前执行顺序只见下方首版工作法：

`语义单元 → 观众此刻缺什么 → 视觉职责 → 主次主体 → 构图家族 → 动画机制 → 音效 → 字幕与停留 → 安全回退`

不能反向从预设库随机挑效果，再寻找一句文案硬套。

五类工具的最新文字研读、待看原视频及执行缺口见研读与项目优化（开发参考资料，未随发布副本附带）。这是候选方法补充，尚未证明新样片观感改善；搜索摘要和平台智能文稿不计作完整视听。
人物构图尤其要分开处理外框形状、框内取景、画布摆位与运动：检查头肩/手势在整段内怎样显示，不能只验证蒙版存在或外框不出画。先确定稳定画面，再设计进退场；这不规定统一人物大小或蒙版形状。

## 第一性原理总规则

### 1. 先分配阅读职责，同期文字只出现一份

铺垫、解释和连接句优先使用稳定普通字幕。承诺、结论、数字、并列项、证据、反转、笑点、结果和空间切换才升级包装。

- 模板完整表达当前句：对应区间关闭普通字幕。
- 模板表达关键词：先把重点分给预设，再生成普通字幕的剩余内容；宁可减少或关闭普通字幕，也不能在另一层重复同词。否定、条件、数字、比较对象和必要限定分配到合适的文字层，原声保持完整。
- 列表完整承载并列项：列表区间关闭普通字幕，结束后恢复。
- 一个连续 `visual_beat` 默认只有一个主视觉职责，不逐名词堆图标和小 B-roll。
- 特殊字幕中承载标题、强调或列表信息的文字，须明显大于本片普通字幕基准；即使同期普通字幕关闭也要比较。阅读大小按实际字形与稳定阶段衡量，不能用多行总高、阴影、描边或入场过冲冒充；具体下限与分工字幕接口见CandidatePlan合同。空间不足先调整预设位置、语义断行、出现时点或选择更合适的预设，不默认缩小视频腾位。

### 2. B-roll 按当前句子与画面的信息职责选择

- 事实、地点、产品、操作、案例、结果：优先寻找真实证据素材。
- 抽象判断、价值表达、承上启下：优先保留人物。
- 素材本身可独立读懂：B-roll 可以短暂成为主画面。
- 人物表情、身份或讲述连续性仍重要：使用分屏、PiP、抠像或卡片，但位置和大小必须适配当前素材。
- 证明事实时必须有真实、相关的证据素材；演示动作、人物反应或补充情境时，可以选择承担对应职责的素材，不能冒充事实证明。
- 完整包装必须实际安排辅助画面及人物与资料的主次变化；单个段落可保留A-roll，整片不能只交人物加字幕。
- 需要补充画面但没有素材时，Agent继续检索本地素材、查找合适外部来源，或制作准确的图表、卡片、背景与示意画面。先看实际素材的可用内容、清晰度、取景及内嵌文字，再决定如何入画；节目封面等自带标题也要与额外字幕去重。真实事实仍须真实来源，示意画面承担说明职责。
- 素材选择执行[共享素材系统](../../../jianying-adapter/docs/MATERIAL_LIBRARY.md)：先本地库，再使用`sucai`站点和中英关键词实际检索、查看具体素材；没有合适结果或主体、清晰度、取景、风格不适合时，生成匹配本片构图的图片、场景、透明元素或背景并检查。可准确用图表表达的关系按内容制作，不能把空框、通用图标当作应有实拍或精细插图的默认替代。入库保存真实来源或生成记录、预览及可用源区间；复用时重新判断当前用途与裁切。
- 每个视觉段在既有`visual_events`的`supporting_visual`中说明职责与状态；缺素材保留`needs_asset`，记录检索词及下一步，不能改写成“不需要”来结束制作。所选辅助画面必须落到实际资源、素材/蒙版操作和时间轴；不靠填写`ready`证明执行。
- 只有追问相应教程依据时，才按需读取 `memos/tutorial-recheck-20260905`；它不作为视频开工、选预设或写入前的固定步骤，不自动续跑其中旧视听任务。本说明书为候选知识，不代表全库存连续视听已完成，也不意味着自动选择器已经接入这些规则。

### 3. 人物处理是构图工具，不是固定语义答案

“观点 → 人物抠像”来自单条教程，只能作为候选。真正判断是：是否需要给标题、列表、证据或空间层次让位。

- 人物仍是主信息：保持正常 A-roll 或轻微推近。
- 人物与证据并重：分屏、PiP、卡片或抠像。
- 证据可独立理解：人物可以缩小或暂时消失。
- 没有空间职责时，不为展示能力而抠像、复制人物或做圆形蒙版。

### 4. 动画服务当前表达，关键帧落实前后状态

放大、缩小、移动、蒙版跟随、人物让位和 B-roll 接管的作用对象承接5.2、时间承接5.3、构图承接5.4—5.5；模板原动画直接沿用，只有额外运动所需的执行参数在5.8补齐，不另填目的、起始、落定、过程、衔接五项规划。目的包括看清细节、建立关系、表达情绪、交接注意力和保持视觉连贯；不要求每次变化都新增事实。原片动作已完成变化时可保持固定取景；新增运动则须落实实际参数，静态缩放不能冒称新增推拉。落定后应有可读、可观察的状态；循环用于明确的情绪或持续状态，并安排退出，不能以长时间运动妨碍阅读。

### 5. 音效绑定动作落点，不绑定句子数量

所选模板原配音效完整沿用。下面的类别仅供5.7确有补声缺口时选用，不要求每片重新选声或替换原配：

- 切换/推拉：速度、呼啸或机械类。
- 元素出现：UI、pop 类。
- 信息爆点/结论砸下：冲击类。
- 情绪铺垫：氛围类。
- 一个节点通常只保留一个主音效；没有动作和语义落点时不撒音效。

## 统一后的 12 类视觉规则

| 规则族 | 触发语义 | 优先画面任务 | 可选构图/机制 | 不触发或回退 |
|---|---|---|---|---|
| 开场揭题 | 原片开场原话 | 前3秒形成强视觉冲击，保持讲述顺序 | 从5.2少量固定开场模板中选与原话匹配的一款 | 不以普通陈述为由自动取消开场包装；按5.2固定试用名单及适用条件起选 |
| 重点/结论 | 核心判断、最终结论、必须记住 | 提升视觉权重 | 短时推近、关键词落锤、结论标题 | 非关键连接句不放大 |
| 弱化/低落 | 真正的低落、尴尬、失落或降权信息 | 降低主体权重，制造情绪距离 | 人物/画面短时缩小、留黑、轻氛围 | 仅出现否定词不自动缩小 |
| 局部聚焦 | 指向局部、细节、一个对象 | 限定注意力范围 | 蒙版、放大镜、圈选、局部降权 | 无明确目标不使用蒙版 |
| 观点表达 | 个人判断、立场、抽象价值 | 保持讲述者可信度 | 人物主导；需要让位时才抠像/错层 | 不因“我认为”自动抠像 |
| 事实/证据 | 产品、地点、数字、操作、案例、证明 | 让观众看到证据 | 全屏 B-roll、证据卡、界面主画面、人物小窗 | 无可靠素材回 A-roll |
| 自身经历/举例 | 过程、经历、例子、真实场景 | 把抽象叙述变成具体情境 | 插图/B-roll、照片、截图、过程卡片 | 泛图库图不能冒充证据 |
| 并列清单 | 3–6 个同级项、步骤或属性 | 建立独立槽位并逐项累积 | 卡片、圆形、纵向、分区、人物+B-roll | 项目非同级或文字过长回普通字幕 |
| 对比/结果 | 前后、好坏、精剪粗剪、方案差异 | 同时看见差异 | 等权分屏、前后卡、结果切换 | 两侧主体尺寸悬殊则不通过 |
| 操作/流程 | 界面步骤、参数、动作过程 | 让操作本身成为内容 | 界面主画面、步骤卡、关键帧跟随 | 界面不可读时不做装饰 B-roll |
| 反应/反转/笑点 | 反应、冲突、笑点、反转落点 | 在落点重置注意力 | 反应插入、短时变形、贴纸、主音效 | 知识解释段不全程综艺化 |
| 创意/构图重置 | 连续 A-roll 单调，且存在真实节奏节点 | 明确改变空间关系 | 位置移动、形变、分层、一次构图重置 | 没有语义落点不为了“网感”乱变 |

## 新增《7种画面效果》的可用结论

这条教程给出的七种映射为：

1. 重点内容 → 画面放大。
2. 低落内容 → 画面缩小。
3. 突出局部重点 → 蒙版。
4. 个人看法/输出观点 → 人物抠像。
5. 自身经历/举例说明 → 合适插图或补充素材。
6. 让画面流畅有趣 → 关键帧。
7. 创意风格 → 画面变形。

其中第 1、3、5、6 条与多来源资料相互印证；第 2、4、7 条高度依赖情景，不能升级为硬规则：

- “低落 → 缩小”只适用于确实需要情绪降权的段落。
- “观点 → 抠像”只有在人物需要给文字或证据让位时成立。
- “创意 → 形变”只能使用已验证、资源完整且不破坏可读性的原生预设。

## 新增《百万博主的剪辑技巧大公开》的可用结论

这条教程给出三个有顺序关系的层级，不应拆成三个互不相关的效果清单：

1. **先保证主体清晰**：二次裁剪、产品聚焦、人物抠像/描边、拍歪与透视修正都服务于“谁是当前主体”。在5.4既有构图工作中落实有效内容区、背景、取景与字幕让位；不另增 `subject_clarity_preflight` 步骤或逐项审批。
2. **再用有限花字建立记忆点**：关键词花字配小动画或小音效，长产品信息改用结构化证据卡。教程给出的保守预算是同一视频花字形式不超过 2 种、颜色不超过 3 种、不要满屏；这只能作为 P2 风格预算，不能替代文字容量、字幕碰撞、画布与动态停留验证。
3. **最后在真实镜头边界选转场**：教程展示后台转场、纸团、向左拉屏、拍摄器、叠化五类样例。它们只证明效果类别和结果形态存在，不证明剪映 8.8 资源、参数或“流量”因果；没有两个真实镜头或前后构图状态时，不进入转场候选。

教程本身的结构也可复用：价格反差钩子同时展示两种结果；三点议程卡只出现一次；顶部三段进度导航常驻并高亮当前章节；普通解释回人物主画面；对比、证据、操作界面和结果样例才升级包装。可迁移的是职责分配，不是其撕纸背景、字体、描边、坐标或顶部导航样式。

## 新增《画中画玩法》的可用结论

这条教程的核心不是固定模板，而是同一时刻两个主体的主次分工：

1. **小窗说话**：证据、界面或 B-roll 做主画面，人物以圆形/圆角小窗保留讲述连续性。优先用于操作教程、屏幕演示和证据必须看清的段落。
2. **人物抠像缩小**：知识卡、背景证据或产品画面做主信息，人物缩到边角或卡片底部继续解释。只有人物确实需要让位时使用。
3. **独立元素居中**：单一产品或对象成为视觉中心，人物可短时退为背景。适合产品展示，但不能同时遮住必须阅读的普通字幕。

统一选择顺序是：`先定主信息 → 判断次主体是否必须保留 → 选择构图 → 按当前素材适配位置大小`。不能根据“知识分享”“产品测评”“好物种草”等题材标签直接套固定坐标。教程示例为 3:4 画布，所有几何参数在 9:16 草稿中必须重做适配。

## 与预设库的关系

教程只产生“语义候选规则”，不能直接产生 `production_ready` 预设。一个节点进入生产 Writer，仍需同时满足：

1. 语义规则命中；
2. 剪映 8.8 资源完整；
3. 目标画布、文字容量、字幕碰撞检查通过；
4. 当前素材完成位置和大小适配；
5. 取得绑定当前素材与节点的真实入场、稳定阅读、退场证据，并通过 CandidatePlan 封版门禁；合同要求先验收的画布适配变体仍须满足相应条件。

已获当前任务授权的独立测试预览可先写入 test profile，再由用户完整播放、验收本片中的预设与声画关系；不要求测试写入前逐个向用户申请预设主观通过。测试写入仍须满足资源、语义、结构和预览合同，不能冒充生产封版。用户对整片的真实反馈绑定同一项目/草稿记录；生产三阶段证据不能代替整片主观验收，整片主观通过也不自动免除封版门禁。具体要求见[CandidatePlan合同](../../../jianying-adapter/docs/CANDIDATE_PLAN_V1.md)。

因此，教程解决“什么时候考虑用”，预设注册表解决“本机能不能用”，当前视频状态解决“这条素材是否确认用”。三层不可互相替代。
