## 已落实的五点改进

1. **调整设计顺序**：先确定稳定构图、文字和阅读状态，再设计运动；所选成套字幕预设同时承接原配音效，保持声画时序，新增预设缺少配套声音时再补齐；统一手册总顺序与后文要求。
2. **补强整片视觉方向**：把“清爽、网感、节奏好”等描述落实到具体参考特征、主次关系、画面密度和全片变化安排。
3. **让规则引用说明适用理由**：在现有设计说明中用一句话解释该规则为什么适用于当前台词与素材，不只填写手册名称。
4. **区分设计判断与效果操作**：五领域的方案、理由和事件引用继续保留，当前融入整片策略与观察需求，旧use/omit表仅兼容；稳定构图可以由实际画面安排表达，所选技术另与执行操作核对。成套预设自带的动画和原配音频按实际导入内容识别，避免为满足校验重复添加关键帧或音效。具体修订沿用现有合同与校验入口，不增加自动审美评分，范围见后文。
5. **明确第五步的结束条件**：每个节点都有实际素材区间、文案、布局、变化与声音安排；代表性关键构图可看，下一步无需临时决定包装方向。字段齐全或校验通过不能代替设计。

## 5.3 视觉段衔接

沿用五项动作：按画面职责变化划分边界，绑定台词和时间，明确观众的理解任务，确定主视觉，再判断次主体是否保留。视觉段可跨多个字幕段；同一句台词需要展示不同信息时也可分为多个视觉段，以实际理解任务和画面变化为准。

每段明确观众此刻要读哪组信息、看哪个动作或比较哪些对象，并确定人物、资料、关系图或文字的主次意图；具体素材区间、人物取景和布局交5.4落实。沿用现有`visual_events`、台词引用和起止时间覆盖全部保留语音；有必要的无口述展示时段明确其作用与时间。每段用`supporting_visual`说明辅助画面已落实、需要找素材或该段无需辅助画面，整片包装须实际安排有内容职责的B-roll、蒙版或背景等辅助画面。后续装配继续使用这些节点及其关联操作，不规定每句都加效果或统一出现频率。

**已接入布局检查的硬约束：平台界面遮挡禁停区。** 用户2026-09-09明确要求加入5.4.5：

- 右下角操作区：点赞、评论、转发等图标占用范围。
- 最底部信息区：作者文案、进度条、搜索词等占用范围。
- 顶部导航区：手机状态栏、关注、返回按钮等占用范围。

上述区域作为合排硬约束，主体和文字的可见占用范围不得侵入；该要求贯穿可见时段，运动过程中也须避让。实际制作时按目标平台、发布画幅和实际播放界面确定边界，并换算到成片画布坐标；不凭经验填写统一像素值。5.4与5.5共用同一组禁停区，现已接入既有布局检查，按可见区域的连续相交判断，不能只检查中心点或是否出画。新v2计划须提供实际界面截图、视频显示矩形及界面区域；具体边界尚未针对当前视频测定。原生底框、复杂动效或人物范围未能测量时，检查结果列出未覆盖项，不能称为全部边界通过。

以“好物分享”候选模式说明选择逻辑：讲使用感受时可由人物主导；展示佩戴/操作时优先看清产品和手部过程；展示细节时让细节取得主视觉；比较时让对象处于可比较的尺度。这些是条件示例，不是每条片必须用齐的固定版式。

该步交出的稳定构图应能说明：观众先看什么、素材展示哪一段、哪些区域不能被裁掉、人物怎样取景、文字在哪里、哪些时点需要留意。缺少必要素材时，先检索当前原素材与本地库存，再在当前授权内寻找外部素材或制作有明确表达依据的图示/背景；记录用途、检索词、实际来源和有效内容区，并查看素材已有文字是否与新增文字重复。缺口仍未解决的节点保留`needs_asset`及下一步，不以“没有合适素材”结束整片设计，也不用无关素材或缩小到不可读来凑布局。

| 子步骤 | 已确认的判断与产出 |
| --- | --- |
| 5.5.1 确定准确文案 | 普通字幕承载已裁决台词；强调字、标题或列表可以提炼，但保留否定、条件、比较对象和必要限定。原素材已有烧录文字时先确认现有表达，避免重复叠加；不能为迁就模板容量删改原意 |
| 5.5.2 分配阅读职责与字幕接替 | 普通字幕默认承载台词；重点字、标题和结构字出现时，普通字幕须让位、缩成未被承接的余句，或在同屏文字已完整表达时关闭。同屏不得再读到两遍同词，不以位置错开视为已去重。用原句字符分工绑定预设与余句，保留否定、条件、比较对象及必要限定；只有明确列出的口头引导词或并列连接词可以有依据地省略 |
| 5.5.3 选定层级与真实样式 | 按5.2方向选择真实预设、字体、字重、配色和必要背景处理，将预设自带动画与原配音效作为成套资源承接；所有承载信息的特殊文字都须比本片普通字幕明显更大，并达到绝对阅读下限。比较稳定阅读阶段的实际字形高度，不能用裸字号、多行总框、padding或入场过冲代替；当前共享门禁的普通字幕参照比值至少1.3。保持同一职责的跨段一致性，并核对实际背景上的对比与可辨性 |
| 5.5.4 用实际文案确定断行与字号 | 按语义和原声分组，保持完整词组及数字/单位关系，用实际字体测量字形、行宽和行距；结合预期手机显示大小查看关键画面。不用统一字数硬切，也不因单句过长让字号逐句忽大忽小 |
| 5.5.5 在可用区域内与主体合排 | 与5.4.5共用平台禁停区，避开必须可见的产品、手势及人物区域。按最终可见外缘安排文字、描边、阴影、底框等占用，进退场和运动途中也不得侵入禁停区；同屏文字明确主次并避免碰撞，使用实际文案回填 |
| 5.5.6 分配稳定阅读与进退场时间 | 先根据本段文字量、理解任务和原声安排稳定可读区间，再给5.6分配入场/退场时间；同组信息按语义逐步建立，保留必要的共同阅读时间，避免抢先揭晓或滞后到意思已切换。容量测量与阅读时间分别判断，最终原生阅读感由用户检查 |

空间不足时，优先调整语义断行、分段或分批呈现；仍不足则与5.4调整共同版式，或选更适合的预设，随后在可读范围内微调字号。原句的完整信息、特殊文字层级和平台禁停区约束持续保留，不能依靠删掉限定或持续缩小字体放行。普通字幕在特殊文字时段关闭时，仍以本片其他普通字幕为参照；全片均由特殊文字接替时须绑定原普通字幕材质与缩放作为参照，不能通过隐藏普通字幕绕过层级要求。

输出沿用现有计划，明确每组文字的准确内容、职责与主次、真实样式、字号/断行、位置、出现与稳定停留区间，以及与普通字幕的接替关系；把阅读时间和允许的运动范围交给5.6。工作法与平台区域检查已实施；具体字体、字号和预设尚未为当前视频选定。

- `content_gate.py`与`caption_replacement.py`新增`distributed_sentence`，让普通字幕仅保留预设未承接的余句，或完整让位。原句逐字分工与实际文字、轨道、时段绑定；不伪造逐字时间，不丢否定、条件或限定。候选和Writer实际写回都复核，写回不一致进入原有恢复路径。
- `visual_planning.py`核对辅助画面的用途、真实来源、操作与实际可见时段。`needs_asset`保持未完成并要求检索词和下一步；单段可无需辅助画面，整片不能全部略过。素材寻找是Agent的制作职责，本次没有新增自动下载服务。

以当前失败的v8候选只读复核，新检查发现4处重点字偏小、6处同屏重复文字及缺少辅助画面安排，原候选字节保持不变。Writer的真实内容校验回归确认：完整余句可以通过，写回丢失“不能盲目”会恢复原索引与状态。详细结果及最终相关回归见本轮验证记录（开发参考资料，未随发布副本附带）。这些结果证明规则和共享检查能识别已知问题，未制作新草稿，也不代表原生视觉验收通过。
